            Needs over features

            Keep the real world in mind. Stay true to the intended problem to address user needs and pain points rather than desires.

            How

            Prioritize addressing pain points over desires, using real scenarios to define practical solutions. Regularly validate your approach with user input and ensure it remains aligned with their real challenges, avoiding unnecessary complexity.
